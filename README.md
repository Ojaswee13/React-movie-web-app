# 🎬 React Movie Web App

A movie discovery web app built with React that lets users browse movies, search for titles, view movie information, and manage their favorite movies.

## ✨ Features

* 🎥 Browse movies
* 🔎 Search for movies by title
* ⭐ View movie ratings and information
* ❤️ Add and remove movies from Favorites
* 📱 Responsive interface
* 🧭 Client-side navigation with React Router
* 🌐 Fetch movie data from an external API

## 🛠️ Tech Stack

* **React**
* **JavaScript**
* **Vite**
* **React Router**
* **CSS**
* **TMDB API**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ojaswee13/React-movie-web-app.git
```

### 2. Navigate to the project

```bash
cd React-movie-web-app/movie_app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Add your API key

Create a `.env` file in the `movie_app` directory and add your TMDB API key:

```env
VITE_TMDB_API_KEY=your_api_key_here
```

### 5. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the application.
